# Shinobi Blast — web build

Turn-based artillery castle siege with ninja and samurai champions. Built with Godot 4.3.

▶ **Play it:** https://undergie.github.io/shinobi-blast/

This repository holds only the exported browser build (`index.html`, `play/`).
It is published automatically from the private source repository; there is no
source code here and nothing to build. Issues and feedback are welcome.
